## 🚀 Featured Projects

### ESP32 LED Control via Wi-Fi

A hands-on project using an ESP32-WROOM-32 to control an LED through a web interface on a cellphone.

**Technologies and components:**
- ESP32-WROOM-32
- Arduino IDE
- C++
- Wi-Fi Access Point
- Web Server
- White LED and 220Ω resistor

**Features:**
- Turn the LED on and off from a cellphone browser.
- Control a GPIO output through a web interface.
- Explore wireless communication and embedded programming.

This is an educational project and a starting point for learning automation and IoT applications.
